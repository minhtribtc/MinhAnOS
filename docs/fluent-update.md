# Fluent workspace update

- Taskbar full width phía dưới, app icons ở giữa; trạng thái và lịch/thông báo bên phải.
- Nền vector xanh tự thiết kế, màu Fluent, cửa sổ Mica và Start/acrylic.
- Font Segoe UI/system, tăng kích thước chữ và khoảng cách, sáng/tối đồng bộ.
- Focus mode mặc định: launcher và app toàn màn hình, giữ instance khi chuyển app.
- Window mode tùy chọn tại Cài đặt → Giao diện → Cách làm việc.
- Calendar hiển thị ngày Asia/Bangkok thật; nút tháng trước/sau và về hôm nay.
- Show Desktop thu nhỏ/khôi phục app, không đóng component.

Không sử dụng ảnh nền hoặc tài nguyên Windows của Microsoft. Ngôn ngữ hiển thị
và thương hiệu là MinhAnOS. Đây là thiết kế lấy cảm hứng từ Windows 11, không phải
bản Windows hoặc ứng dụng tương thích Windows.
